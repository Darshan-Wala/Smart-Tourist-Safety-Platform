# 🛠️ Installation

```bash
git clone https://github.com/Darshan-Wala/Smart-Tourist-Safety-Platform.git

cd Smart-Tourist-Safety-Platform
```

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm start
```

### Machine Learning

```bash
cd ml
pip install -r requirements.txt
python train.py
```
